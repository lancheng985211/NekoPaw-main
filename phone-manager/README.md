# 墨水屏管家 Android 1.0.0

APK：NekoPaw-Manager-1.0.0.apk。独立包名com.nekopaw.manager，不替换此前外卖助手；Android 8.0及以上，target35。通过WebView打开ESP32本机管理网页，现有编辑/保存能力沿用固件，不需要电脑常开。修改后按网页中的保存按钮，资料存放在ESP32。不开启或修改外卖采集。

## 安装使用

1. 将APK传到手机，点击安装。系统提示时，允许当前用于打开安装包的应用安装此APK。
2. 手机开启热点，让ESP32连接该热点；也可以手机与ESP32连接同一Wi-Fi。无需ESP32自己开热点。
3. 打开“墨水屏管家”，设备地址填 http://192.168.1.100:81 ，保存。IP变化时以ESP32串口实际IP为准；此处填写ESP32地址，不是手机热点网关。
4. 点“测试连接”只读取设备状态。默认打开备忘录，顶部可进入宠物、课表、天气、日历、Codex、外卖、备忘录。原网页的切屏按钮让物理屏幕切页；App原生功能栏打开手机管理页。
5. 在备忘录添加事项、选择时间/表情、保存到设备；课表等按现有页面保存。手机断网不能继续读取或保存到ESP32，已保存在设备的数据仍在。此App不提供独立离线编辑同步队列。

只申请网络访问和网络状态权限；不申请通知、无障碍、短信或文件读取权限。地址在App私有设置中保存，Android清除应用数据会重置地址。手动输入设备地址，不自动扫整个网络。设备HTTP接口与原网页一致。

App仅允许内嵌WebView访问所设设备的同一来源，禁文件访问、无JavaScript桥，外部网站的用户点击链接交系统浏览器。网络错误提示可在App顶部看到；设备返回404通常需上传包含该功能的固件。新固件或更换IP后点刷新。竖横屏切换保留当前页面和未关闭的编辑视图；系统回收进程时未保存网页草稿可能丢失。
