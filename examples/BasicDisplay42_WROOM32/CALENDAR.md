# 设备本地日历

与已确认 A 方案一致：顶部年月，中间整月（日为每周第一天），当天黑底白字，格内节日／节气及右上角休／班，底部当天详情与农历。六行月份自动压缩行高。

## 更新与使用

在本示例运行 PlatformIO `esp32dev` 的 Build 和 Upload，Upload 后 Monitor 波特率115200。设备连接热点后会打印 `Calendar page: http://实际IP:81/calendar`。

手机或电脑与设备在同一可访问局域网，打开该网址，点击“屏幕显示日历”。课程管理与天气页也有日历入口。GPIO32按键下一页，GPIO33上一页，循环课表→天气→日历；其余两页待实现。网页不会自行抢占设备当前页面。

启动沿用原来的课表／天气页面选择；更改后使用独立 `activePage` 键保存三页选择，课表键与天气缓存不改动。旧电脑端 page_switcher.py 应关闭，以免演示图片覆盖设备页面。

## 日期、来源与范围

- 北京时间（UTC+8），与现有课表／天气使用同一个设备时钟。NTP或课程／天气／日历网页校时。断电重启如果尚未校时，显示等待校时；不伪造当前日期。持续供电断网可继续走时。
- 日历仅在当前可见并跨天、校时变化或切页时刷新，自动换月／换年；不持续刷墨水屏。
- 设备内置2026-01-01至2030-12-31农历和二十四节气，无需联网逐天查询。表共1826天，3652字节。2026 CSV与文本逐日交叉校验，五年文本检查日期完整、星期与连续农历日期、每年24节气。来源原件和SHA256在tools/calendar-data/。
- 官方休／班目前收录2026年。未收录年份照常显示公历和已收录的节日／节气，明确提示“当年休班未收录”，不会沿用2026调休。
- 2030之后仍显示公历及可确定的固定日期／星期节日，明确提示农历与节气数据未收录。扩展数据或添加新的官方年度休班需要更新程序；本版没有实现在线抓取公告或网页上传年度数据。
- 含元旦、春节、清明、劳动、端午、中秋、国庆，及元宵、七夕、重阳、教师节、母亲节（5月第二个周日）、父亲节（6月第三个周日）。闰月不重复计算传统节日。普通周末不冒充法定假期。
- 节日和节气重合时日期格优先节日，底部同时列出，例如2026-06-21父亲节＋夏至。清明作为节日及节气只列一次。
- 日历休／班仅为国家通用安排，学校是否补课仍按实际课表和指定日期调整，不自动改课表。

官方来源：

- https://www.hko.gov.hk/tc/gts/time/calendar/text/files/T2026c.txt （2027—2030同名年份文件）
- https://data.weather.gov.hk/weatherAPI/hko_data/calendar/nongli_calendar_2026.csv
- https://www.beijing.gov.cn/cs/gncs/zcwj/202603/t20260327_4568275.html （国办发明电〔2025〕7号）

## 网页接口

- GET /calendar：日历和管理入口，无外部脚本／字体依赖。
- GET /api/calendar：当天年月日／星期、当月每日标签／休班、农历、完整详情、收录范围、当前屏幕页面。
- POST /api/page：`{"page":"calendar"}`，原 course/weather 继续有效。
- POST /api/clock：沿用已有北京时间校准接口。
