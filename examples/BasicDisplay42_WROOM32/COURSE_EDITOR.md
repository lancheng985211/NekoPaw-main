# 按课程添加课表

工程：<项目目录>\examples\BasicDisplay42_WROOM32。

## 手机操作

1. 正常 Build、Upload，Monitor（115200）中读取 `Course editor: http://设备IP:81/`。手机/电脑连接同一 Wi-Fi 后打开地址；手机热点也可以先尝试访问。
2. 首页“学期设置”：填第一周的周一日期、总周数（默认20，支持1～30）。这决定今天是第几周。
3. 点击“＋添加课程”，填写课程名称、任课老师（选填）。
4. 在“上课时间1”中点击“课程周数”，在底部弹窗点选周数，也可选单周、双周、全选或清空；点确定。
5. 点击“上课时间”，选择星期、实际开始与结束时间，再填写该次上课的教室。
6. 同一门课一周有多次课时，点“＋添加其他上课时间”。每个时间单独设置星期、周数、钟点、教室。最后点顶部“保存”。例如一门课可在周一上午第1～8周上301教室，周四下午双周上202教室。
7. 首页按课程列出已有记录，可以编辑或删除一门课程。设备按当天星期与教学周选出实际课程，再按开始时间排序到墨水屏的五行内。

界面参考了用户截图的课程卡片与周数底部弹窗。上课时间采用实际钟点；尚未提供学校节次作息表，因此不把“第几节”自动换算成具体时间。

## 临时调整

“临时调课”选择具体日期，继承当天实际生效课程。可修改、补课或取消该节；保存后仅覆盖当天。取消当天调整会恢复常规课程安排。临时调整优先，不受原课程周数或学期边界限制。

同一周、同一天的时间重叠会阻止保存；相邻时间允许。同一天最多五节课。不同周的课程可以使用同一时间，不算冲突。当前最多40门课程、合计70个上课时间、10个临时日期，总JSON不能超过6000字节；达到任一限制时提示，原数据保留。

## 保存与升级

使用 ESP32 Preferences/NVS 保存，断电后保留，写入失败不替换运行课表。课程设置与老师等由设备保存，无需电脑服务。日期按北京时间，NTP或打开网页校时；彻底断电后须重新校时。个别生僻字/表情可能不在墨水屏中文字库中。

旧版按星期填五节课的数据会在内存中转换为课程列表，同名课程归在一起，其上课时间、周数、教室与临时调整保留。用户第一次成功保存才写入新格式；读取或转换失败时禁止覆盖旧数据，并在网页提示。普通 Upload 不选择 Erase Flash。升级后刷新浏览器页面。

课表管理端口81，原 NekoPaw bridge端口80。使用此功能时关闭旧电脑 page_switcher.py，避免演示图覆盖课表；其他四页真实数据和设备端五页切换仍未接入。网页用于可信局域网，未提供登录，不对公网开放。

## 验证范围

编译与模拟网页检查不能代替设备实测。烧录后检查：添加同一门课的多个时间 → 不同周生效 → 临时调整仅影响当天 → 断电再启动并校时后内容仍存在。旧数据转换也需在实际设备升级后确认。
